# Core Principles

## Foundational Approach

This research protocol is built on six core principles that must guide all analytical decisions.

---

## Principle 1: Null Hypothesis Default

**Statement:** Assume every bank is PRAGMATIST (no meaningful CDM engagement) until evidence proves otherwise.

**Rationale:** 
- Only 4 institutions globally have confirmed CDM production
- Most banks have not publicly committed to CDM
- Starting from "no engagement" prevents confirmation bias

**Implementation:**
- Do NOT carry forward assumptions from original framework
- Require positive evidence to classify as ARCHITECT
- "No evidence" = PRAGMATIST classification (with confidence penalty)

**Burden of Proof:**

| Upgrade Path | Evidence Required |
|--------------|-------------------|
| PRAGMATIST → ARCHITECT-Follower | Tier 1/2 evidence of active contribution OR announced pilot |
| ARCHITECT-Follower → ARCHITECT-Leader | Tier 1 evidence of production commitment with timeline |
| ARCHITECT-Leader → ARCHITECT-Native | Confirmed production AND governance leadership |

---

## Principle 2: Evidence Triangulation

**Statement:** No classification should rest on a single source. Require corroboration for high-confidence findings.

**Rationale:**
- Single sources may be outdated, biased, or misinterpreted
- Triangulation catches errors and builds confidence
- Different source types reveal different aspects of truth

**Implementation:**

| Confidence Target | Minimum Evidence |
|-------------------|------------------|
| 90%+ | 2+ independent Tier 1 sources |
| 70-89% | 1 Tier 1 OR 3+ Tier 2 sources |
| 50-69% | 2+ Tier 2 sources |
| 30-49% | Tier 3 or inference only |

**Corroboration Rules:**
- Same fact from same original source republished elsewhere ≠ corroboration
- Vendor claiming bank uses their product + bank confirming = corroboration
- Two independent trade press articles citing different sources = corroboration

---

## Principle 3: Integrated Adversarial Thinking

**Statement:** Challenge findings throughout the research process, not just at the end.

**Rationale:**
- Post-hoc challenges are cognitively harder (anchoring bias)
- Early challenges prevent wasted effort on wrong hypotheses
- Continuous challenge builds more robust conclusions

**Implementation:**
- Mini-adversarial checkpoint after each evidence tier
- Full adversarial pass for Tier A banks
- Abbreviated adversarial for Tier B banks
- Single adversarial question for Tier C banks
- Pre-mortem analysis before research begins

---

## Principle 4: Calibrated Confidence

**Statement:** Confidence levels must be earned through evidence, not asserted.

**Rationale:**
- Overconfidence leads to framework errors
- Underconfidence fails to leverage good research
- Calibration enables appropriate caveating in deliverables

**Implementation:**
- Use explicit confidence anchoring criteria (see `/methodology/confidence-calibration.md`)
- Apply "would I bet at these odds?" test
- Require consistency across banks with similar evidence
- Document confidence rationale, not just level

---

## Principle 5: Explicit Uncertainty

**Statement:** Document what we don't know as rigorously as what we do know.

**Rationale:**
- Unknown unknowns are the greatest risk to framework accuracy
- Explicit gaps enable targeted follow-up
- Uncertainty documentation prevents false precision

**Implementation:**
- Every bank output must include "Key Uncertainties" section
- Every phase synthesis must include "Confidence Gaps" analysis
- "Unknown" is a valid classification (better than false precision)
- Flag specific validation paths for each uncertainty

---

## Principle 6: Framework Coherence

**Statement:** Individual bank classifications must be internally consistent with each other and with anchor points.

**Rationale:**
- Inconsistent classifications undermine framework credibility
- Peer comparisons are a key client use case
- Incoherence signals analytical errors

**Implementation:**
- Cross-validation against anchor points (Pass 5)
- Peer comparison consistency check (Phase Synthesis)
- Ordinal ranking test (can we rank banks by engagement level?)
- Similar profile test (do similar banks have similar classifications?)

---

## Applying the Principles

### Decision Hierarchy

When principles conflict, apply this hierarchy:

1. **Framework Coherence** — Classifications must be internally consistent
2. **Evidence Triangulation** — Multiple sources required for high confidence
3. **Null Hypothesis Default** — When in doubt, classify as Pragmatist
4. **Calibrated Confidence** — Match confidence to evidence strength
5. **Explicit Uncertainty** — Document gaps rather than guess
6. **Integrated Adversarial** — Challenge conclusions but don't paralyze

### Common Traps to Avoid

| Trap | Description | Prevention |
|------|-------------|------------|
| **Confirmation Bias** | Finding what we expect to find | Null hypothesis + adversarial |
| **Anchoring** | Over-weighting first evidence found | Probability updating after each tier |
| **Availability** | Over-weighting vivid/recent evidence | Systematic search across all tiers |
| **False Precision** | Stating confidence without justification | Calibration criteria |
| **Coherence Neglect** | Ignoring peer inconsistencies | Cross-validation pass |

---

## Principle Violations

If you find yourself doing any of the following, STOP and reconsider:

- Classifying as ARCHITECT without Tier 1 or 2 evidence
- Stating confidence >70% with only one source
- Skipping adversarial checks "because the answer is obvious"
- Ignoring contradictory evidence because it's inconvenient
- Copying a peer's classification without independent evidence
- Proceeding past a reasoning gate without completing it

These are protocol violations that compromise research quality.
